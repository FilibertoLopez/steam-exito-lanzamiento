# Transcripciones de Zoom

- **Cómo obtenerla:** Zoom → *Grabaciones* → sesión → descargar *Audio transcript* (`.vtt`). Requiere grabación en la nube con transcripción activada.
- **Formato:** se guarda el `.vtt` original como `AAAA-MM-DD-tema.vtt`. Si se prefiere texto plano, se puede agregar también `AAAA-MM-DD-tema.txt`.
- **Privacidad:** contienen nombres y comentarios textuales de los integrantes; mantener el repositorio privado.
