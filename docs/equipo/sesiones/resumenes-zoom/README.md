# Resúmenes de Zoom

Resúmenes generados automáticamente por Zoom (AI Companion / *Meeting Summary*).

- **Cómo obtenerlo:** Zoom envía el resumen por correo al anfitrión o lo muestra en *Grabaciones y transcripciones → Resúmenes*. Cópialo tal cual, sin editar.
- **Formato:** Markdown, `AAAA-MM-DD-tema.md`.
- **Encabezado sugerido:**

```markdown
---
fecha: AAAA-MM-DD
fuente: Zoom AI Companion
sesion: ../AAAA-MM-DD-tema.md
---
```

El resumen de Zoom es la versión automática; la nota de sesión (`../AAAA-MM-DD-tema.md`) es la versión revisada por el equipo y la que manda.
