# Notebooks

Ejecutar en orden numérico. Cada notebook exporta sus figuras a `reports/figures/` con el prefijo del notebook (p. ej. `02_eda_*.png`) y sus métricas a `reports/metrics/`.

- Los notebooks numerados se versionan **con** resultados para que las gráficas se vean en GitHub.
- Los de `borradores/` se versionan sin resultados (`nbstripout`).
